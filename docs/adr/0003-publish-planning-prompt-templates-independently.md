# Publish planning prompt templates independently

FounderOps administrators can publish each of the four planning prompt templates independently so they can revise one template while work on another is still in progress. FounderOps retains one active version per template, and the authenticated planning context returns the active general, Initiative, Deliverable, and Sub-Issue templates to eligible profiles in the configured audience. Edits stay in local browser drafts. A successful publication clears only the draft for the published template.

Administrators save the audience separately so they can prepare templates before enabling them. The audience starts as an empty selection and can target selected profiles or all eligible profiles.
