# Planning Item reads

- Before adding or changing an Item reader, shared loader caller, candidate search, aggregate or machine context, read `docs/planning-item-read-contracts.md`. Update its consumer entry, sources, coverage and evidence.
- Common authoritative selection, eligibility, ordering and exact set summaries belong in the shared read module. Database selection precedes page limits. Preserve existing machine formats and complete logical scopes.
- Use only the existing credential boundary and declared read adapters. A new exception needs the exact edge, reason, maintainer, substitute evidence and expiry recorded with its contract.
